# Классификатор документов (Document Classifier)

Используйте этот навык для идентификации типов документов и подготовки их к "Цифровому двойнику" (Digital Twin).

## 1. Типы документов и Индексация
Для каждого документа ИИ должен присвоить цветной визуальный индекс:
- 🟦 **ח-1, ח-2...** (Договоры / חוזה).
- 🟪 **מ-1, מ-2...** (Спецификации / מפרטים).
- 🟩 **כ"כ-1, כ"כ-2...** (Сметы / כתב כמויות).
- 📙 **פ-1, פ-2...** (Протоколы совещаний / פרוטוקולים).

## 2. Паттерн "Digital Twin"
При обработке всегда разделяйте:
1. **Physical Storage**: Ссылка на оригинальный файл (PDF/Word) в Supabase Storage.
2. **Machine-Readable**: Чистый JSON-массив данных, извлеченный ИИ, для использования в Радаре и Сметчике.

## 3. Идентификация (Immutable Code)
Каждому документу присваивается несменяемый код доступа в формате `DOC-CTR-XXX`. Этот код используется в официальных письмах как юридическая ссылка.

## 4. Логика распознавания
- Если документ является Протоколом (פרוטוקול), ИИ должен искать в нем ключевые фразы "Изменение", "Дополнительно", "Замена материалов".
- Если документ является Чертежом, ИИ должен извлечь номер ревизии и дату утверждения.
