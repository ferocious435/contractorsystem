# Генератор писем (AI V.O. Composer)

Используйте этот навык для создания официальных требований о выплате за дополнительные работы (V.O. / חריגים) и уведомлений о противоречиях.

## 1. Структура письма (מכתב דרישה)
Все письма должны быть на **иврите** и иметь профессиональный юридический тон. Стандартная структура:
1. **Заголовок (נדון)**: Четкое название проекта и номер претензии.
2. **Основание (רקע)**: Ссылка на пункт договора или протокол, породивший требование.
3. **Описание (תיאור העבודה)**: Что именно было сделано сверх контракта.
4. **Финансовый блок (Бизнес-правило 18%)**:
   - Цена за единицу (до НДС).
   - Общая сумма **до НДС** (סה"כ לפני מע"מ).
   - **Сумма НДС (18%)** (מע"מ 18%).
   - **Итоговая сумма с НДС** (סה"כ כולל מע"מ).

## 2. Доказательства (Приложения)
В конце письма ИИ должен автоматически перечислить приложения (נספחים):
- Ссылки на фото/видео из полевого интейка.
- Ссылки на пункты BOQ.
- Маркеры доказательств `[1]`, `[2]` из Радара.

## 3. Ограничения
- ИИ не берет на себя юридическую ответственность, но должен готовить текст так, чтобы подрядчику оставалось только нажать "Печать".
- Все суммы должны быть проверены на арифметическую точность.
 Be concise, respectful but firm.
