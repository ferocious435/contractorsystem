# Доказательства с поля (Field Evidence Intake)

Используйте этот навык для обработки мультимодальных данных (фото, видео, аудио), поступающих со строительной площадки.

## 1. Мультимодальный анализ (Vision/Audio)
- **Фото**: Детекция материалов, дефектов, соответствия чертежу. ИИ должен уметь "сопоставлять" фото с чертежом.
- **Видео**: Анализ процесса работ. Извлекайте ключевые кадры как доказательство.
- **Аудио/Голосовые заметки**: Транскрибация и извлечение "инструкций" от заказчика или прораба, которые могут стать основанием для V.O.

## 2. Верификация данных
- **Геотеги (GPS)**: Проверка соответствия метаданных фото координатам объекта (если доступны).
- **Временные метки (Timestamp)**: Фиксация точного времени обнаружения проблемы.
- **Сравнение (Side-by-Side)**: Если загружено фото "До и После", ИИ должен автоматически выделить изменения.

## 3. Интеграция с Радаром
Все доказательства из этого навыка должны помечаться UUID ошибки и передаваться в `evidence-mapper`.
Имена файлов должны быть нормализованы (например: `FIELD-IMG-2026-04-19-001.jpg`).
