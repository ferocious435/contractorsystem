# Радар противоречий (The Radar)

Используйте этот навык для поиска конфликтов между контрактом (חוזה), чертежами и фактическим выполнением работ.

## 1. Структура анализа (Card-Based Audit)
Каждый найденный конфликт должен быть оформлен в виде "Карточки угрозы":
- **Уровень угрозы (Threat Level)**: `HIGH`, `MED`, или `LOW`.
- **Факт противоречия (The Fact)**: Четкое, сухое описание конфликта без лишних слов.
- **Стратегия защиты (אסטרטגיה מומלצת / Lawyer Mode)**: Перейдите в режим "Адвоката подрядчика". Посоветуйте юридическую или коммерческую тактику (например, как обосновать дополнительные расходы на основе конкретного пункта договора).

## 2. Интерактивные доказательства (Proof Markers)
Любое утверждение ИИ **обязано** сопровождаться ссылками на источник в формате `[1], [2]`.
- При упоминании статьи сметы или пункта договора, указывайте индекс документа.
- Подготовьте данные для всплывающих окон (snippets), чтобы пользователь видел пруф мгновенно.

## 3. Логика управления (Action Flow)
При взаимодействии с карточками:
- **העבר לתמחור (To Pricing)**: Если пользователь нажимает эту кнопку, передайте UUID ошибки и все её параметры в навык `pricing-ledger-il`.
- **רענון (Local Rescan)**: При обновлении одного документа (например, нового протокола), пересчитывайте только затронутые карточки, а не весь проект.

## 4. Группировка
Группируйте карточки по "Файлу-источнику" (например: "Ошибки из Протокола совещания №5").
Если одна карточка влияет на другую, ставьте пометку 🔗 *"Связанная стыковка №..."*.
