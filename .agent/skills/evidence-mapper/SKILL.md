# Карта доказательств (Evidence Mapper)

Этот навык отвечает за создание неразрывной связи между утверждением ИИ (например, "Цена завышена") и первоисточником в документах.

## 1. Визуальные маркеры (Markers)
Любое утверждение, переданное в Радар или Сметчик, должно иметь индексный маркер в формате `[1]`, `[2]`, `[3]`.
- Маркеры должны быть последовательными внутри одной карточки.
- ИИ обязан хранить в скрытых полях карточки метаданные: `{ "id": 1, "source_id": "DOC-CTR-001", "page": 12, "text_snippet": "...", "coordinates": "..." }`.

## 2. Юридическая сила (Legal Link)
При подготовке письма в `vo-letter-composer-il`:
- Имена документов в ссылках должны соответствовать их кодам (`ח-1`, `מ-1`).
- Цитата должна быть приведена на оригинальном языке документа (обычно иврит), даже если отчет на русском.

## 3. Проверка достоверности
Если ИИ не может найти 100% подтверждение в тексте, маркер ставить **ЗАПРЕЩЕНО**. Используйте фразу: *"Предположительно на основе контекста, прямое доказательство отсутствует"*.
