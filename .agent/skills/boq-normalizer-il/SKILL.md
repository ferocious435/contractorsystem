# Нормализация смет (BOQ Normalization)

Используйте этот навык для обработки любых табличных документов: Смет (כתב כמויות), Прайс-листов и Таблиц выполнения.

## 1. Обязательный формат (Standard Columns)
Каждая нормализованная смета должна содержать следующие колонки (названия могут варьироваться, но смысл должен быть сохранен):
1. **Код (סעיף)** — Номер статьи по классификатору или смете.
2. **Описание (תיאור)** — Текст работы.
3. **Ед. изм. (יחידה)** — м2, м3, м/п, шт и т.д.
4. **Количество (כמות)** — Числовое значение.
5. **Цена (מחיר יחידה)** — Строго **БЕЗ НДС**.

## 2. Логика обработки
- **OCR Fallback**: Если файл является сканом или плохим PDF, используйте Gemini Vision для извлечения.
- **Детекция НДС**: Если в исходном Excel есть итоговая цена с НДС, ИИ обязан вычислить базовую цену: `Price_Base = Price_Gross / 1.18`.
- **UI Валидация**: Перед записью в БД, подготовьте данные для экрана "Screen of Truth", где пользователь сможет подтвердить правильность маппинга колонок.

## 3. Вывод
Результат всегда должен быть в формате валидного JSON, готового к вставке в таблицу `contracts_boq` или `ledger_items`.
