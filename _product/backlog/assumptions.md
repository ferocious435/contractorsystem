# Предположения R02–R04

| ID | Утверждение | Основание | Диапазон исходов | Где используется | Статус |
|---|---|---|---|---|---|
| A1 | Уже установленный Docker доступен для подготовки изолированной тестовой БД | Первоначально API не отвечал [S5]; после уточнения владельца сервер29.7.2 отвечает [S6] | Доступный Docker / повторный отказ среды | Проверка транзакций в проекте R02–R04 | Доступность Docker подтверждена29 октября; сама тестовая БД ещё не создана |
| A2 | Существующая локальная конфигурация позволит получить полезный редактируемый текст письма | Адаптер уже используется другими функциями, сервер доступен [S3][S4]; качество писем ещё не проверялось | Пригодный черновик / непригодный ответ, требующий корректировки подхода | Срез B локальной генерации | Не подтверждено |

Проверка чувствительности: отказ A1 меняет готовность способа проверки, но не разрешает заменять её записью в реальные данные или объявлять мок равным транзакционному тесту. Отказ A2 не отменяет ценность ручного черновика с правильными суммами, но R04 не принимается и модель не меняется автоматически. Числовых оценок сроков/качества или RICE-ранжирования на этих предположениях нет.
