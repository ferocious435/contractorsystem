## 2. Обязательное логирование навыков (Skill Logging)
**КРИТИЧЕСКОЕ ПРАВИЛО:** В конце каждого ответа или отчета ИИ **ОБЯЗАН** добавить секцию `💡 Активные навыки (Слой A / Слой B):` с перечислением использованных в задаче навыков. Это сделано для прозрачности и экономии токенов.

3. Составить краткий маркдаун-план формата: Намерение -> Навыки -> Решение.

## 3. Рекомендация к планированию
Если задача требует изменения нескольких слоев (Схема БД -> API -> UI), ИИ обязан разбить задачу на **Track** и следовать циклу RARV (Reason -> Act -> Reflect -> Verify). Запрещено делать массовые замены за один подход без валидации Typescript и UI.
