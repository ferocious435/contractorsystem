# Контекст Проекта: ContractorSystem (Израиль)

## Описание
Система управления контрактами и сметами для строительных подрядчиков в Израиле. Цель — защита коммерческих интересов подрядчика через автоматический поиск противоречий в документах и расчет стоимости дополнительных работ (חריגים).

## Целевая Аудитория
- Израильские строительные компании и индивидуальные подрядчики.
- Инженеры ПТО (חשב כמויות).

## Ключевые функции
1. **Парсинг смет (BOQ / כתב כמויות)**: Локальное извлечение данных из Excel и текстовых PDF.
2. **Радар Противоречий (Contradiction Radar)**: Поиск несоответствий между договором (База) и рабочими чертежами/планами.
3. **Финансовый учет (Pricing Ledger)**: Расчет цен на дополнительные работы (V.O.) с использованием цен Dekel или кастомного анализа.
4. **Доказательная база (Evidence Mapping)**: Привязка утверждений к конкретным страницам и пунктам документов.

## Финансовые стандарты
- **Валюта**: Израильский шекель (₪ / ILS).
- **НДС (VAT / מע"מ)**: **18%**. Все суммы в БД хранятся БЕЗ НДС.
- **Язык интерфейса**: Иврит.
- **Язык логики/разработки**: Русский/Английский.
