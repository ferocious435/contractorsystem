# Техническая Архитектура

## Стек технологий (MVP)
- **Фронтенд**: Next.js 16 (App Router), React 19, TypeScript.
- **Стилизация**: Tailwind CSS v4 (Luxury Minimal).
- **БД и Авторизация**: Supabase PostgreSQL + Auth (Row Level Security).
- **Хранилище**: Supabase Storage (бакеты `project-documents`, `vo-evidence`).
- **ИИ**: Gemini 3.1 Pro High (мультимодальный анализ: текст, фото, видео).

## Структура проекта
- `/src/components/features`: Изолированные компоненты бизнес-логики.
- `/docs/specs`: Спецификации PRD.
- `/supabase`: Миграции и настройки БД.

## Принципы обработки данных
- **Локальный парсинг**: Текстовые данные извлекаются скриптами до отправки в ИИ для экономии токенов и точности.
- **Асинхронность**: Обработка тяжелых документов (50+ страниц) идет в фоновом режиме через очереди.
- **Безопасность**: Данные строго изолированы на уровне `project_id`.
