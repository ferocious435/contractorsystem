# Локальный ИИ для сравнения документов

Проект использует Ollama и модель `qwen3:4b` только для радара расхождений. Эта модель выбрана после проверки на компьютере с видеокартой 6 ГБ: она работает заметно быстрее версии 8B. Запросы модели отправляются на `http://127.0.0.1:11434` и не уходят во внешний сервис ИИ.

## Установка на новом компьютере

```powershell
winget install --id Ollama.Ollama --exact --accept-source-agreements --accept-package-agreements
ollama pull qwen3:4b
```

Добавьте в локальный `.env.local`:

```dotenv
AI_PROVIDER=ollama
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3:4b
```

Файл `.env.local` содержит настройки конкретного компьютера и не сохраняется в GitHub.

## Проверка

```powershell
npm run verify:local-ai
```

После запуска приложения статус модели виден в боковой панели. Контрольная проверка сохранённого случая открывается только внутри учётной записи и не изменяет базу:

```text
/local-ai-check?findingRef=C-CE6070
```

Внутренний адрес `/api/scan/preview` возвращает результат этой проверки для диагностической страницы.

Обычный радар сохраняет название поставщика и модели в новой карточке. Сигнатура анализа также учитывает модель, поэтому результаты разных моделей не смешиваются.
