# PRD: Главная страница (Main Page) & Login
**Статус:** 🔒 Заблокировано (Согласовано)

## 1. מסך התחברות (Login Screen)
- **UX/UI:** Тёмная тема (Dark Mode), минималистичный премиальный дизайн. Строительные/инженерные паттерны на фоне.
- **Поля:** Имя пользователя, пароль.
- **Опции:** Чекбокс `זכור אותי` (сохранить сессию) — включён по умолчанию.
- **Данные для MVP:** Захардкожено `admin` / `admin`. Ролевая модель пока не применяется.

## 2. עמוד הבית (Главная страница - Список проектов)
- **UX/UI:** 100% RTL (иврит). Тёмный фон.
- **Действие "+ פרויקט חדש":** Мгновенное (1-click) создание новой карточки без промежуточных форм. Карточка заполняется плейсхолдерами (`NEW-***`, `שם המזמין`, `₪0`).
- **Сетка проектов (Grid):**
  - Адаптивные размеры карточек: при увеличении количества проектов на странице, размер карточек плавно уменьшается, чтобы все или большинство помещались без бесконечного скролла.
- **Карточка проекта (Project Card):**
  - Область: Вся карточка выступает кликабельной зоной для перехода внутрь проекта (`לוח בקרה`).
  - Изображение: Разные/уникальные фотографии по тематике בנייה/תשתיות для визуальной дифференциации проектов.
  - Отображаемые данные: Внутренний ID/Badge, Название (שם), Заказчик (לקוח/מזמין), Бюджет (תקציב).
  - Управление: Иконка `⋮` (три точки) для вызова контекстного меню.
- **Контекстное меню (⋮):**
  - `מחיקה` (Удаление) — обязательно с диалогом подтверждения `?האם אתה בטוח`.
  - В будущем: экспорт, дублирование.
