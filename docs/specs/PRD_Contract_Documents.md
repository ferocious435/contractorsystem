# PRD: מסך מסמכי חוזה (Contract Documents)
**Статус:** Согласовано базовое видение + Архитектура двойного хранения

## 1. Цель Экрана
Служить неизменяемой базой (Якорем) проекта. Хранит все юридически обязывающие документы, утвержденные при подписании контракта.

## 2. Функциональные требования (UX/UI)
- **Мульти-загрузка (Bulk Upload):** Поддержка Drag & Drop сразу десятков файлов с мгновенной отрисовкой в списке.
- **Dynamic Indexed Avatars (Умные иконки):** Для быстрого визуального сканирования вместо картинок-превью используются цветные квадратные аватары с автоматически растущим индексом (например: 🟦 **ח-1**, 🟦 **ח-2** (договоры), 🟪 **מ-1** (спецификации), 🟩 **כ"כ-1** (сметы)).
- **Встроенный просмотрщик (In-App Viewer):** Пользователь может читать PDF, Word и фото прямо в интерфейсе.
- **Идентификация:** Каждому документу присваивается Immutable Classification Code (Несменяемый код), например: `DOC-CTR-001`. Этот код используется в судебных письмах и ссылках ИИ.

## 3. Архитектура обработки данных (Dual-Storage / Digital Twin Pattern)
Применяется паттерн двойного хранения для баланса между юридической надежностью и скоростью ИИ.

1. **Physical Storage (Хранение оригиналов):**
   - Все загруженные файлы сохраняются *в исходном виде* (Original File) в Supabase Storage. Они выводятся во встроенном Viewer'е как юридическое доказательство.
2. **Machine-Readable Storage & Validation (Трансформация для ИИ):**
   - Сразу после загрузки срабатывает фоновый процесс (Асинхронная Очередь).
   - *Экстракция:* Текстовые документы парсятся в Markdown, Excel - в JSON. Графические сканы и плоские PDF отправляются в Gemini 3.1 Vision для OCR-сборки таблицы.
   - *Обязательная UI Валидация (Screen of Truth):* Если документ является таблицей/сметой (Особенно Скан!), после парсинга система выводит модальное окно. Слева - скан, справа - чистая цифровая таблица HTML. Человек **обязан** визуально подтвердить "Маппинг колонок" (с помощью выпадающих списков: תיאור, כמות, מחיר) и исправить возможные опечатки ИИ. 
   - Только после нажатия 🟢 **"קלוט למערכת"** чистый и проверенный JSON сохраняется в PostgreSQL для использования анализатором.
