# PRD: Дашборд Проекта (Project Dashboard)
**Статус:** Согласовано (Бизнес-ориентированная модульная архитектура SaaS + Мультимодальный ИИ)

## 1. Концепция SaaS и Монетизация (Product-Led Growth)
Система спроектирована так, чтобы модули можно было продавать по отдельности (Tiers). Интерфейс жестко разделяет Базовый функционал, Премиум-пакет для коммерции и Enterprise-пакет для ИИ-анализа аудио и видео со стройплощадки.

## 2. Информационная архитектура (Tier-based Sidebar Layout)

### 📦 אזור 1: מסמכים ובקרה (Base Subscription / Документы и Контроль)
*Хронологический рабочий процесс проекта.*
- **מסמכי חוזה (Contract Documents):** Якорь проекта. Сюда загружаются обязывающие тендерные документы (Сметы, Договоры, Исходные планы).
- **מסמכי עבודה (Work Documents):** Документооборот во время исполнения. Сюда загружаются новые версии планов, переписки, инструкции.
- **בקרת סתירות (Discrepancy Control):** Результат сканирования ИИ. Экран автоматически найденных противоречий в текстах и таблицах.

### 💎 אזור 2: כלים מסחריים (Pro Subscription / Коммерческие инструменты)
*Опциональные функции монетизации. Генерация денег, оценка рисков.*
- **תמחור (Pricing Module):** Финансовый калькулятор. Превращает проблему в реальный счет (V.O.) на основе прайс-листов.
- **יועץ AI (AI Commercial Advisor):** Интерактивный помощник для юридических и финансовых задач.
- **מחולל מכתבים חכמים (Interactive Smart Letter Generator):** Интерактивный редактор юридических писем (WYSIWYG + AI Чат) для генерации требований Заказчику.

### 🎥 אזור 3: תיעוד שטח (AI) (Enterprise Subscription / Умный Журнал Работ)
*Высший уровень SaaS-подписки. Анализ фотографий, видео и голоса со стройки.*
- **ניתוח תמונות שטח (Photo AI Scan):** Прораб загружает фото со стройки. ИИ Vision сканирует его, задает наводящие вопросы ("Вижу, что труба проложена иначе, чем на плане. Есть ли последствия?") и автоматически распределяет выводы в "Запросы денег" (תמחור).
- **ניתוח וידאו וקול (Video & Voice AI):** Запись видео + голосовые диктовки с площадки. ИИ понимает юридические последствия, формулирует инженерную проблему и сразу готовит проект счета (V.O).

### ⚙️ מחירונים (Price Lists / Системные базы)
- **מחירונים:** База данных расценок (вынесено отдельной кнопкой без лишнего заголовка группы). Место для загрузки справочников (Декель, корпоративные прайсы), на которые опирается модуль `תמחור` при расчетах стоимости.
