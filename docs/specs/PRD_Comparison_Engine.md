# PRD: בקרת סתירות (Сравнение и Контроль Противоречий)
**Статус:** Согласовано (Бизнес-логика, UX и Архитектура "Радара")

## 1. Цель Экрана
Единый командный центр (Inbox) для всех конфликтов в проекте. Строгое разделение: экран `בקרת סתירות` — это ЕДИНСТВЕННОЕ место, где появляются карточки (тикеты) угроз. Документарные разделы (`מסמכי חוזה` и `מסמכי עבודה`) остаются чистыми репозиториями. 

## 2. Функциональные требования (UX/UI - Card Feed)
Система работает не как чат, а как лента карточек, сгруппированных по файлу-источнику (например: "Ошибки из Протокола от 01.07").

**Структура Карточки Тикета:**
- **Ярлыки:** Дата обнаружения и Уровень Угрозы (HIGH, MED, LOW).
- **Факт Противоречия:** Белый толстый шрифт, четко описывающий конфликт (без воды).
- **Стратегия (אסטרטגיה מומלצת):** Серый блок, где ИИ переходит в режим "Адвоката" и советует подрядчику юридическую/коммерческую стратегию защиты.

**Интерактивные Доказательства (Стиль NotebookLM):**
Каждое утверждение ИИ сопровождается визуальными маркерами `[1], [2]`. При наведении/клике на маркер всплывает локальный скриншот или вырезанный текст из Сметы/Чертежа. Подрядчик получает пруфы мгновенно, без ручного поиска.

## 3. Кнопки Управления на Карточке (Action Flow)
Пользователь — верховный судья. У него есть контроллеры:
- `X` / **התעלם (Скрыть):** Игнорировать проблему. Карточка исчезает, ИИ вычеркивает этот факт из уравнения.
- `🔄` / **רענון (Ре-генерация):** Локальный рескан. Заставляет ИИ перечитать *только* эту карточку (при загрузке нового письма или изменении прайс-листа), экономя деньги на Глобальном Скрин-аудите.
- `טופל` (Слева внизу): Пометить как "Решено / В архиве".
- `העבר לתמחור` (В центре): Ключевая кнопка. Передает математику этой ошибки в финальный финансовый модуль для выставления счета.

## 4. Архитектура Данных и ИИ
- **Индексация ID:** Визуально карточки нумеруются по порядку (`#01, #02`), и при удалении одной, список динамически "схлопывается". Системно в БД (SQL) каждая угроза имеет неизменяемый UUID (`ERR-042`) для надежной передачи в модуль Смет.
- **Meta-Conflicts (Скрытые связи):** ИИ строит граф конфликтов. Если две разные карточки противоречат друг другу, на карточке возникает умная плашка 🔗: *"Внимание: Эта карточка связана со Стыковкой #5"*.
