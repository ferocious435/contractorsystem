# PRD: UI/UX & Design System (Дизайн, Эстетика и Motion)
**Статус:** Ожидает утверждения (Pending Approval)

## 1. Концепция Дизайна (Design Philosophy)
**“Modern Bloomberg Terminal” – גרסה קבלנית** (Версия для Подрядчиков).
Цель: Создать ощущение **абсолютного контроля над рисками (שליטה מוחלטת בסיכון)**. Система — это торговый терминал Уолл-Стрит, военный командный центр. Не сайт. Не базовая ERP. Не CRM.
- Глубокий Dark Mode (функциональность для работы по 8–10 часов).
- Высокая плотность данных, острая иерархия.
- Резкое снижение когнитивной нагрузки (Progressive Disclosure).
- Отсутствие декоративных элементов без функции.

## 2. Цветовая Палитра и Глубина
Слои глубины:
*   **Главный фон (רקע ראשי):** `#0B0F14`
*   **Рабочие области (משטחי עבודה):** `#11161D`
*   **Второстепенный слой (שכבה משנית):** `#151C24`
*   **Тонкие границы (גבולות):** `rgba(255,255,255,0.06)`

### Цвета Действий (Action Colors)
Максимум 4 цвета:
1.  **Глубокий Синий / Primary CTA (#3B82F6):** Обычное действие. Технологичность.
2.  **Оранжевый / Secondary CTA (#F97316):** Привлечение внимания.
3.  **Финансовый Зеленый (#00D084):** Позитив. Прибыль, корректность, утверждение.
4.  **Холодный Красный (#FF4D4F):** Критика. Только для существенных ошибок и расхождений.

## 3. Типографика (Typography)
*   **Текст (Иврит / Основной):** `Fira Sans` (с подменой на ивритские совместимые шрифты при необходимости, например Rubik).
*   **Числовые данные (Сметы, Суммы, Заголовки):** `Fira Code`.
*   **Иерархия:** H1 (20-22px), Primary Data (14px), Secondary (12-13px), Meta (11px). Огромные цифры (суммы) – 24-32px Mono.

## 4. Glassmorphism (Контролируемый стеклянный эффект)
Используется **только** для "интеллектуального" слоя (Панель ИИ, Модальные окна, Контекстные слои).
*   Blur: 4-8px
*   Opacity: 0.85-0.92
*   Светлая рамка и глубокая, мягкая тень (Soft Shadow).

## 5. Система Анимаций (Motion System = Information)
**Главный принцип:** Если нет новой информации — нет движения.
Движения алгоритмичны, точны, тихи и быстры. Строгий запрет на: bounce, elastic, сильный zoom, parallax и "геймерские" неоновые эффекты.

### 5.1 Тайминги (Критично)
*   **Hover:** 120–160ms
*   **Открытие панели (Slide 80-140px):** 180–240ms
*   **Появление оповещения:** 220ms
*   **Обновление данных / Fade 숫자:** 300ms
*   *Любая анимация в системе строго до 400ms.*

### 5.2 UX-Хореография (Micro-interactions)
*   **Data Hover (Умное наведение):** Без ярких цветов. Тонкое внутреннее свечение (Glow) и граница (Border) за 150ms (ощущение precision targeting).
*   **Выделение строки (Target Locked):** Внутренний Highlight, мягкий Glow. Боковая панель открывается плавно, сопровождаясь мягким автоскроллом к строке.
*   **Смена статуса:** Плавное свечение 400ms и затухание (Approved -> Зеленый Fade, Risk -> Янтарный, Critical -> Красный).
*   **Real-Time Ощущение:** Плавное добавление новых логов. Микроиндикатор "Updated 3s ago". Легкое "дыхание" системы (пульсирующая точка "System live").

### 5.3 ИИ и Аналитика (AI Animation Behavior)
*   **Состояние "AI На связи / Думает":** Спиннеры (Spinners) запрещены.
    *   *Scan line:* Тонкая линия сканирует таблицу.
    *   *Pulse dot:* Точка в углу и текст "AI analyzing pricing anomalies…".
    *   *Text streaming:* Строка заполняется в стиле консоли терминала.
*   **Найдена обычная проблема (Insight):** Легкий Cyan Glow вокруг зоны, мягкое появление текста (без pop-ups).
*   **Критическая проблема:** Холодная красная боковая полоса, однократное мерцание (без дрожания), жесткий фокус (Lock focus) на проблеме + медленный Pulse.
