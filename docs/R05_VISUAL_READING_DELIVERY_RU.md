## Что уже работает

Для PDF программа составляет перечень физических страниц, получает изображения страниц и читает их существующим рабочим GPT. Для Word она отдельно учитывает текст, встроенные изображения и все места их использования. Числа сверяются повторным независимым чтением с учётом строк, столбцов и подписей. Подтверждённые единицы сохраняются и используются повторно без нового запроса к GPT.

Неполное чтение сохраняет прежний полный текст. Подтверждённый текст отдельной картинки доступен и тогда, когда другая часть документа остаётся непроверенной. Изменение полного текста создаёт историю чтения: прежняя точная цитата открывается в соответствующей версии. Описание фотографии показано отдельно и не выдаётся за дословную цитату.

Есть отдельное чтение источника, обычный анализ и штатная загрузка с проверкой дубликатов. Ход работы восстанавливается после перезагрузки страницы; отмена, изменение источника и поздний ответ проверены. Чтение вручную подтверждённого документа сохраняет его ручной статус и анализ. Финансовые записи при этом не создаются.
