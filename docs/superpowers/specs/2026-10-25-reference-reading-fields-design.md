# Сведения о чтении документов в отчёте 1.4

25 октября 2026 года владелец отдельно выбрал общий список полей для отчёта и загрузчика, одобрил этот короткий проект и подтвердил порядок выполнения. Объём — bounded, небольшое исправление. Реализация выполняется по согласованному плану.

## Цель

Отчёт о справочных источниках должен учитывать настоящее состояние чтения договорных PDF. Сейчас GET /api/scan/support-sources не запрашивает ocr_status и storage_path, хотя использует проверку, зависящую от этих сведений. На сохранённом наборе отчёт теряет девять договорных источников и показывает отсутствие недостающих нормативов.

## Рассмотренные подходы

Выбран общий список полей для отчёта и загрузчика: оба пути получают одинаковые исходные сведения, а последующее изменение списка выполняется в одном месте. Альтернатива — дополнить только запрос отчёта; она требует меньше строк, но оставляет два расходящихся списка. Владелец выбрал первый подход.

## Решение

В существующем серверном модуле загрузчика будет один общий список: id, title, category, doc_type, extracted_text, parsed_json, ocr_status, storage_path. Его используют обычная загрузка источников и запрос документов для отчёта. Место общей константы — технический выбор исполнителя в рамках существующего модуля, без новой подсистемы.

Передаются исходные сохранённые значения. Отсутствующий статус не заменяется на COMPLETED. Проверка покрытия страниц, черновиков и фрагментов остаётся обязательной. PDF с неполным чтением не становится договорным основанием из-за исправления запроса. Полный текст и служебный путь остаются на сервере; формат публичного ответа отчёта сохраняется.

## Приёмка

- На неизменном сохранённом наборе установленный отчёт показывает те же 9 договорных источников, 2 справочника и 29 отсутствующих отдельных нормативных текстов, что и полный повтор загрузчика. Распознанные номера не объявляются независимо проверенным официальным реестром стандартов.
- При одинаковых входных данных результат отчёта совпадает с результатом обычной загрузки. Строгий допуск глав по-прежнему показывает неопределённость редакций; исправленные счётчики не доказывают применимость.
- Автоматическая проверка выполняет настоящий обработчик отчёта с учётом запрошенных колонок, воспроизводит потерю сведений до исправления и успешный результат после него. Отдельно проверяются неполный PDF и распознавание PDF по storage_path при заголовке без расширения.
- TypeScript, профильные проверки, production-сборка, прямой вход и основные экраны установленной программы проходят. Документы, карточки, цены и финансовые связи сохраняются; это подтверждается сравнением снимков.

## Границы

Редакции справочных глав, смысловой подбор цен и исключение технических карточек из новых дополнений остаются следующими отдельными решениями 1.4. В этой правке не меняются модельные правила, библиотечные записи, пользовательские выводы, расчёты и права доступа. Общий скан, OCR и повтор обработки не запускаются; приостановленные материалы сохраняют состояние.

Работа выполняется в текущем чате и ветке без дополнительных исполнителей. После одобрения этого проекта составляется план реализации. Общая приёмка 1.4 остаётся частичной до выполнения остальных условий.
