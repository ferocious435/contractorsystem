# R02–R04: черновики писем, согласованные суммы и локальная обработка — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` для последовательного выполнения в текущем чате. Шаги отмечаются `- [ ]`. Дополнительные исполнители, клиенты моделей и worktree запрещены действующими правилами владельца.

**Goal:** сохранить редактируемый черновик с проверяемыми суммами и источниками, отдельно отмечать отправку и обеспечить согласованный локальный путь письма/консультанта.

**Architecture:** общая чистая финансовая модель обслуживает список, письмо и экспорт. PostgreSQL атомарно сохраняет снимок и отдельно меняет статус отправки через существующий Supabase; текущий адаптер Ollama готовит только проверяемый текст. Два последовательных выпуска: A — R02/R03; B — R04.

**Tech Stack:** существующие Next.js/React/TypeScript, Supabase/PostgreSQL, Node test runner и Ollama. Docker используется только для синтетической тестовой PostgreSQL, через `docker exec` без нового PostgreSQL-клиента приложения.

**Spec:** [одобренный проект](../specs/2026-10-29-draft-letters-money-local-design.md), SHA256 `0a055e0c29768f983297ba1636ca08320b9f51555d5d64d6e997bf1da92e561b`. Одобрение владельца29 октября: `01a187c3-3fc7-7021-acd1-0dee187bc07b`, EV10. Утверждённые байты проекта не редактировать; его прежняя надпись «ещё не одобрен» относится к моменту предъявления.

**Статус плана:** подготовлен для проверки владельцем. Реализация, тестовая БД и миграция ещё не начаты. Метод выполнения уже определён: текущий помощник, текущий чат, без субагентов. Проверка этого плана ещё не подтверждена.

## Global Constraints

- «Основная цена `pricing_ledger` хранится до НДС»; существующие поля ledger/contract не заменяются gross.
- «Итог набора — сумма уже округлённых индивидуальных итогов»; ставка проекта `0.18`, скидки и надбавки повторно не применяются. Производные VAT/gross допускаются в одобренном снимке письма.
- «Клиентские суммы не являются доверенным входом»: расчёт, принадлежность и версии проверяются заново внутри операции БД.
- «Прежние SENT-записи сохраняются с прежним смыслом и данными»; нет массового пересчёта, выдуманной даты отправки или достраивания старого снимка.
- «Открытие не вызывает модель»; отправка адресату выполняется вне приложения. Статус означает отдельную ручную отметку пользователя.
- «Новые модели, клиенты и внешний запасной обработчик не вводятся». Сохраняются текущая конфигурация Ollama и `src/utils/contract-scan-quality.ts`.
- Настоящие документы, письма, деньги и модельный кэш не используются для пробных записей; защищённая папка владельца только для чтения. Нового OCR/прохода корпуса нет.
- Основной3002/r8 остаётся доступен до проверки контрольного выпуска. Внешние браузеры не открываются; визуальная проверка — встроенный браузер, настоящий масштаб не подменяется CSS.
- Изменения владельца сохраняются; только явный stage относящихся файлов. Не менять модель/режим чата, системные настройки и зависимости приложения.
- Принятые1.3/1.4/MTM не переоткрываются; D3,1.2 и1.5 сохраняют отдельные незакрытые условия.
