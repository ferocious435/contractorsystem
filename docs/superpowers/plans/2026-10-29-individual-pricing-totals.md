# Полные итоги отдельных расценок — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Владелец прямо запретил субагентов и разрешил выполнить план в текущем чате; дополнительного выбора исполнителя и повторного разрешения не требуется.

**Goal:** Каждая готовая расценка показывает полный индивидуальный итог с НДС, подробности открываются только для чтения, общая сводка отделена от списка.

**Architecture:** Добавить чистую модель представления поверх сохранённых сумм до НДС, существующих функций финансового расчёта и сохранённых оснований цены. Один результат используется в строке, подробностях и суммировании, без повторного применения скидки или налога. Сохранённая проверка условий либо явная ручная отметка подтверждают, что корректировки уже включены в введённую цену; неподтверждённое остаётся незавершённым.

**Tech Stack:** TypeScript, React, Next.js, существующие компоненты titanium, node:test и React SSR; без новых зависимостей.

**Spec:** `docs/superpowers/specs/2026-10-29-individual-pricing-totals-design.md` — одобрен владельцем 29 октября: «כן, מאשר את המתווה שהצגת. תמשיך לתוכנית העבודה ולביצוע.»

## Global Constraints

- Ветка `codex/recovery-audit-2026-09-07`, текущий чат; без worktree, субагентов, других AI-клиентов и изменения модели.
- Базовые суммы хранятся до НДС; пользовательские данные и серверные проверки цены не менять ради отображения.
- Не запускать реальные модельные операции, OCR, синхронизацию, подтверждение, удаление или генерацию письма ради проверки интерфейса. Только синтетические записи для действий.
- Сохранить dirty-файлы владельца, owner dedup, исходники и кэш; Git stage только по явному списку изменённых файлов этой функции.
- Сборка только из подготовленного `release-source`, новый неизменяемый output; порт 3002 переключать после G1–G5, при сбое вернуть предыдущий output.
- Приёмка D3 остаётся частичной; новые финансовые экраны проверяются заново, прочие принятые проверки без новой причины не повторяются.

## Review Focus

1. Скидка/надбавка уже включена в сохранённую цену: не применять повторно; ручное подтверждение устаревает при изменении чисел.
2. Нет количества, цены, ставки или подтверждения условий: не превращать в ноль; подтверждённая нулевая доплата остаётся нулём; отрицательный кредит не теряется.
3. Налог округляется у каждой расценки: сводка складывает готовые индивидуальные итоги; нет повторного налога и потери агорот.
4. Одна работа имеет несколько версий либо ID повторён: не складывать альтернативы и дубликаты; отправленная строка не означает финансового утверждения; договорная база отдельно.
5. Длинные суммы, 125%/200%, 501/24293 строк, открытие подробностей: полный текст доступен, виртуализация/фокус/запреты выбора сохраняются, открытия не вызывают анализ или запись.
