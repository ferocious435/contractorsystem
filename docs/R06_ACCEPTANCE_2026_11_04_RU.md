## Фактические возможности IAB

Доступны `visibility` и `viewport`; переключения настоящего zoom, coarse/touch и Reduced Motion инструмент не предоставляет. Обычный размер составил 923×707 CSS px, DPR 1.25; `coarse=false`, `reducedMotion=false`, страница видима. **DPR 1.25 не принят за доказательство браузерных 125%.**

Команда viewport 375×812 дала фактически 300×650 CSS px. Эта попытка сохранена отдельно как `o04-photo-request375-actual300`. После коррекции запрос 469×1015 дал измеренные 375×812; только эти снимки названы `actual375`. CSS zoom и подмена `matchMedia` не применялись. Временное изменение размера сброшено.

В изолированной области чтения инструмента `requestAnimationFrame` и `performance` недоступны. Это не утверждение об отсутствии этих API в самом браузере. Кадры по такому наблюдению не вычислялись. Ограничения и точный ответ владельца сохранены в `browser-capabilities-and-owner-scope.json`.

Начальное отсутствие IAB было связано со скрытым новым чатом и устранено после открытия чата владельцем. У перехода к S14 истекло ожидание инструмента, но следующая проверка увидела целевую страницу без повторной навигации. Причина задержки не установлена. Ранний снимок `o04-partial-source-normal` сделан до готовности предпросмотра; он не является приёмкой оригинала PDF. Для оригинала фотографии использовано окончательное состояние с загруженным изображением.
