## Настоящий рабочий случай — EV45/EV47

В системе есть настоящий черновик VO-1783855967 по MTM с одной финансовой связью. Он относится к старому формату: новый номер редакции и полный финансовый снимок у него не были сохранены. Они не достраивались задним числом.

Сама ContractorSystem получила предпросмотр по настоящей финансовой строке этого проекта. Суммы нового снимка — сохранённый в проекте нулевой дополнительный расчёт; новая цена не придумывалась. Оба относящихся источника отмечены REQUIRES_VERIFICATION. Непроверенные документы не получили нового подтверждения, официальный тип по тем же данным отклонён с HTTP422.

## Отдельный незакрытый риск входа — EV48/R1

При одновременном запуске двух проверок нового входа без cookies одна получила HTTP503 до проверки сохранения; другая завершилась успешно. В журнале Supabase Auth за это окно подтверждены403/otp_expired и One-time token not found. Установленный механизм для каждого нового входа создаёт и проверяет одноразовое подтверждение. Эти данные указывают на конкуренцию подтверждений; точная форма погашения/замены токена отдельно не устанавливалась.

После последовательного создания входа все5 HTTP-проверок R02 прошли. Отдельная обычная проверка входа тоже прошла. Это не исправление параллельного входа: проблема остаётся открытой, авторизация в R02 не менялась. Она зарегистрирована для отдельного решения владельца; не скрыта повторным зелёным запуском.
