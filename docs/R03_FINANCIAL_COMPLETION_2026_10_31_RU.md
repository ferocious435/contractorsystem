Исполняется исходный R03 из `a6509c79:docs/WORK_PLAN_CURRENT_RU.md`, полное поручение EV49 и прямое продолжение владельца с R03. ## Что исправлено и убрано

Graphify показал оставшийся отдельный денежный путь в `ProjectOverview`: НДС начислялся заново на общую сумму расценок. Регрессионный пример с тремя строками по0,03 давал0,11 вместо суммы индивидуальных результатов0,12. Это искусственный граничный пример теста; такие строки в Кирьят-Гат не добавляли.

Обзор теперь использует принятый расчёт `prepareLetterFinancialSnapshot` через `getOverviewFinancials`. Базовый договор учитывается отдельно; НДС расценок складывается после индивидуального округления. Известная утверждённая сумма сохраняется при неизвестной ожидающей; неопределённый общий итог не превращается в ноль. Альтернативные и конфликтующие записи не складываются как независимые работы. Отправленные работы допускаются только для чтения сводки; пригодность для нового письма не расширена.

Удалены неиспользуемые `totals` из старого состояния ledger, их передача в интерфейс, тип `PricingLedgerTotals` и старые карточки `PRICING_LEDGER_STAT_CARDS`. Текущая сводка уже использовала индивидуальный расчёт. Потребители проверены по графу и текущим файлам; удаление не затронуло финансовые строки, архив или письма.
