# БИЗНЕС-ЛОГИКА И СТАНДАРТЫ ПРОЕКТА CONTRACTORSYSTEM

Этот файл заменяет собой устаревшие своды правил. Все правила здесь **обязательны к выполнению**.

## 1. Языковые стандарты
- **Агенты ИИ:** Общение с пользователем (ответы в чате) на **русском языке**.
- **Интерфейс (UI):** Все элементы интерфейса должны быть ИСКЛЮЧИТЕЛЬНО на **иврите (עברית)** (RTL).
- **Данные документов:** Цитаты, названия и юридический контент из документов остаются на **иврите (עברית)**.

## 2. Финансовые стандарты
- **Валюта:** Израильский шекель (₪).
- **База данных:** Суммы хранятся **БЕЗ НДС**.
- **НДС:** Ставка **18%**.

## 3. PRD-First Development
Запрещено писать код без анализа требований из `docs/specs/`.

## 4. Архитектурный стиль
- **Фронтенд:** Next.js (App Router), React 19.
- **БД:** Supabase.

## 5. Защита от регрессий
Использование TypeScript и TDD.

## 6. Стандарты AI Моделей (Gemini 3)
- **СТАНДАРТ:** Основная модель для всех задач (Анализ и OCR) — `gemini-3.5-flash`.
- **КОНФИГУРАЦИЯ:** Все вызовы через `src/lib/gemini.ts`.
- **БРЕНДИНГ:** В UI отображать только "Powered by Gemini 3.5 Flash".
