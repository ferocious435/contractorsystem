# Порядок работ R02–R04

Источник объёма: одобренный проект EV10. Канонический рабочий план: [восемь задач](../../docs/superpowers/plans/2026-10-29-draft-letters-money-local.md). До проверки владельцем это предлагаемый порядок, не разрешение реализации и не календарный baseline.

M1 — общие деньги (задача1) → M2 — атомарная запись/HTTP (2–3) → M3 — установленный выпуск A (4–5) → M4 — установленный локальный выпуск B (6–8). Исполнитель каждой вехи — текущий Codex. Критерии готовности и обязательные зависимости заданы в каноническом плане; отдельные копии не создаются.

Временные оценки и срок завершения не согласовывались, числовой резерв не назначен. Ограничения Docker/CLI/IAB и непроверенное качество текста отражены в gates плана. Следующий шаг — проверка плана владельцем, затем executing-plans по сохранённому методу.
